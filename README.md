# 如言 · Ru for VS Code

如言的独立 VS Code 扩展。语言实现与规范在 [uppet/ru-language](https://github.com/uppet/ru-language)，本仓库只维护编辑器支持。

## 功能

- `.ru` 文件识别与 TextMate 语法高亮：中文 / Unicode 名称、匿名 `算` / `作`、控制流、数字、中文行 / 块注释与 # / // 行注释，以及四对可跨行的引号。
- 半角 / 全角括号匹配、引号补全、常见多行块的保守自动缩进。
- 函数、过程、匿名函数、条件、循环、恢复块、形、元初和竞赛模板。
- 编辑器右上角 ▶、命令面板“如言: 运行当前文件”，以及 **Ctrl+Alt+R**（macOS：**Cmd+Option+R**）。
- 在 VS Code 任务终端运行：保留 stdin、stdout、stderr 和退出状态，支持交互输入与 Ctrl+C。

对应如语言规范 **0.19.6**（实用库需要 0.12.0+；作用域块和赋值别名需要 0.11.0+）。扩展不包含解释器；没有 LSP、实时语义诊断、补全服务或调试器。

## 安装

1. 在扩展视图的 `…` 菜单选择 **Install from VSIX…**，选择 `ru-vscode-0.8.2.vsix`。
2. 安装 Python 3.10+，准备如言工具链。
3. 在设置中搜索 `ru.cliPath`，设为语言仓库根目录的 **ru 文件**的绝对路径，而不是目录、`ru.cmd` 或 Python 文件夹。

例如用户设置：

```json
{
  "ru.interpreterPath": "python3",
  "ru.cliPath": "/Users/me/Projects/ru-language/ru"
}
```

Windows 示例：

```json
{
  "ru.interpreterPath": "C:\\Python312\\python.exe",
  "ru.cliPath": "C:\\Projects\\ru-language\\ru"
}
```

若该 Python 环境已能执行 `python3 -m rulang`，`ru.cliPath` 可以留空。Windows 默认解释器名为 `python`，其他系统为 `python3`。路径不要额外加 shell 引号；空格和中文原样填写。扩展不会从源码目录自动寻找或执行一个叫 `ru` 的文件。

## 如竞与如观（统一如:模块导入）

竞赛模块使用 `尽 取 外言 '如:竞'.`；`contest` / `竞赛` / `rujing` 片段已更新。13 个公开函数不变，普通 CLI 仍可运行。旧 `如竞`、`如观`、`如:竞赛` 导入会报迁移提示，无兼容别名；产品名仍是如竞、如观。

可视模块使用 `观 取 外言 '如:观'.`，再写 `图 取 观 其 画布 480 320.`；使用模块别名方便重复执行代码格。`ruguan` / `如观绘图` 插入基本柱形绘图片段，`ruguan-interactive` / `如观交互` 插入逐帧动画、点击暂停示例。将这些示例放到如书代码格运行：默认使用 Python，也可显式勾选「JS 加速」使用 browser-js。VS Code 的“运行当前文件”仍使用普通 CLI，不会打开绘图窗口；普通 CLI、C 和 Node.js 目标不提供如观宿主，CLI 的 `check` 也会报告绘图能力限制。

`画布 宽 高` 创建画布，支持背景、填色、描边、线宽、字号、矩形、椭圆、线、文字。颜色写六位 `#RRGGBB` 或八位 `#RRGGBBAA`（末两位是不透明度），填色/描边可传 `空` 取消。`每帧` 接受一个帧序号参数的回调；鼠标按下/松开回调为横、纵、键三个参数，鼠标移动为横、纵两个参数，按键/松键为一个键名参数。`帧率` 控制动画，`停` / `继续` / `关闭` 无参成员不写括号。

每个如书会话仅一个活动画布。执行新格、停止或重启会关闭旧画布交互，已显示的静态画面保留。扩展提供片段和 `外言` 悬停说明，不内置绘图运行器。

### 如观形状、变换与裁剪（Ru 0.19.0／如书 0.8.0）

`ruguan-transform` / `如观变换` 插入可在如书 Python 或显式 browser-js 运行的小示例：矩形裁剪内平移、旋转、双轴缩放，再绘制三角形与多边形，并显式配平保存／恢复。

- `三角形 横一 纵一 横二 纵二 横三 纵三`、`多边形 点阵` 使用原生闭合路径，按当前填色、描边与线宽绘制，采用 nonzero 填充。点阵须为含 3～256 个点的阵，每点是恰含两个坐标的阵；重复点、退化、自交允许，提交后修改原阵不会改变已绘形状。
- `平移 横 纵`、`旋转 弧度`、`缩放 横倍率 纵倍率`、`变换 a b c d e f` 都右乘当前矩阵。Canvas 六参数满足 `x′=a*x+c*y+e`、`y′=b*x+d*y+f`。旋转用弧度，正角在屏幕上顺时针；零与负缩放合法。所有数值参数及累积矩阵分量必须有限且绝对值不超过 100000。
- `保存`／`恢复` 保存和恢复矩阵、裁剪与全部样式，最多 64 层，空栈恢复报错。初始绘图及每次回调结束必须配平，否则报错并关闭交互；显式关闭或新建画布可丢弃旧栈。`段` 或花括号退出不会自动恢复绘图状态。
- `裁剪 横 纵 宽 高` 叠加矩形交集，最多 32 个，调用时快照当时矩阵；之后的变换不会移动已有裁剪。宽高非负，零宽或零高是空区域。`取消裁剪` 清空当前裁剪；`重置变换` 仅重置当前矩阵，不改变已有裁剪。无参成员直接写 `图 其 保存.` 等，不写括号。
- 形状提交时快照矩阵与裁剪。`背景` 清除整个画布及先前绘制命令，不受变换和裁剪限制，同时保留当前样式、矩阵、裁剪与保存栈。每次回调开始重置矩阵、裁剪与保存栈，样式跨回调保留；鼠标横纵仍是画布坐标，不逆变换为局部坐标。每帧 2048 条命令及约 256 KiB 的既有预算不变。

这些是普通成员名，扩展仅在 `其` 后高亮和显示词法提示，不新增保留字，也不判断接收者类型。CLI 启动行为不变，不提供绘图宿主；不依赖新的编辑器命令。

### 如观透明颜色与文字对齐（Ru 0.19.1+／0.19.2+）

透明颜色与构色需要 Ru **0.19.1+**；文字对齐需要 Ru **0.19.2+**。安装扩展不升级解释器。如书对应最低版本分别为 0.8.1／0.8.2。

- 六位 `#RRGGBB` 完全不透明；八位 `#RRGGBBAA` 的 `00` 全透明、`ff` 完全不透明、`80` 为 128/255。大小写均可，不接受三／四位缩写、颜色名、`rgb()` 或前后空白。`填色 空`／`描边 空` 表示跳过绘制，与合法透明色不同。
- `观 其 颜色 红 绿 蓝 不透明度` 是模块导出的普通算，四参必需且为 0～255 有限整数，返回小写 `#rrggbbaa`。拒绝事实、空、小数和越界，不钳位或舍入。命名参数精确为 `红:`、`绿:`、`蓝:`、`不透明度:`；一次调用不混用位置和命名实参。它不是画布成员；Python CLI 的 `run` 可单独构色，`check` 与 C／Node.js 编译目标仍按模块能力限制拒绝如观。
- `背景` 先清空整幅画布，再在透明底铺指定颜色，不与之前的图形或上一帧叠色。每个命令帧从透明底完整重绘；半透明背景不会自动留下拖尾。背景不受变换／裁剪限制，并保留当前样式与保存栈。
- `图 其 文字对齐 横向 纵向` 返回空，两参均必需。横向仅接受精确句值 `'左'`／`'中'`／`'右'`，纵向为 `'上'`／`'中'`／`'下'`／`'基线'`；命名参数为 `横向:`、`纵向:`。新画布默认左／上，不表示参数可省略；不接受英文别名、空白或空。
- `文字 文 横 纵` 的横纵是局部坐标锚点。基线指字母基线；纵向中使用字体 em 框中线，不保证字形墨迹精确居中。对齐跨回调保留，由 `保存`／`恢复` 保存，`背景` 不重置；每条文字命令冻结提交时的对齐、颜色、字号、矩阵及裁剪。尚无文字测量、自动换行和字体选择。

`ru-color`／`如观构色` 是可在 Python CLI 运行的构色示例；`ruguan-text`／`如观文字对齐` 在如书 Python 或显式 browser-js 演示透明底、居中标题、右侧基线与保存／恢复。这些仍是普通名称，仅在 `其` 后有上下文提示，不新增保留字。

### 如观秒制计时（Ru 0.19.3+）

`ruguan-time`／`如观计时` 插入按实际帧间隔移动、显示经过秒的示例，点击暂停，按键继续。它需要 Ru **0.19.3+**／如书 **0.8.3+**，在如书 Python 或显式 browser-js 运行。

- `图 其 经过秒`、`图 其 间隔秒` 是零参数、只读数值成员，不写括号；新画布初值均为 0。宿主在每次有效回调开始时以单调时钟取快照，同一次回调内冻结；回调外沿用上次快照，反复读取不会推进时间。
- `经过秒` 从画布创建计时，包含暂停、隐藏期间的真实时间。`间隔秒` 仅在帧回调内给出与上一实际帧开始的间隔；初帧与停后继续的首帧为 0。鼠标／键盘回调内间隔为 0，不改变上一帧时间。
- 重复 `继续` 或运行中重绑 `每帧` 不重置计时。隐藏／迟到后的间隔不截断、不补帧；物理模拟可自行限制积分步长。计时不扩展回调预算，不提供等待功能。
- `每帧` 的回调仍只接受一个帧序号参数；两个时间成员是普通名称，不是新的保留字。保存／恢复绘图状态不应用于计时。

### 如观弧与扇形（Ru 0.19.4／如书 0.8.4）

`ruguan-arc`／`如观弧扇` 插入扇形与逆时针弧的短示例。两者签名均为 `横 纵 宽 高 始角 转角`，六参均必需；命名参数精确为 `横:`、`纵:`、`宽:`、`高:`、`始角:`、`转角:`，同次调用不混用位置和命名实参，返回空。

- 横纵是外接框左上角，宽高非负；全部为绝对值不超过 100000 的有限数，拒绝事实、空与句。零宽高允许，按原生退化椭圆路径处理。
- 始角和转角均为弧度，零角在椭圆右侧；转角是带符号的扫过量，不是终止角。未镜像局部屏幕中正值顺时针、负值逆时针，负缩放会镜像方向。非圆椭圆使用参数角，端点为 `(cx + rx*cos(θ), cy + ry*sin(θ))`，不是中心到端点的几何极角。
- `弧` 是开放路径，只用描边与线宽，忽略填色。部分 `扇形` 从中心连起点、沿弧到终点再闭合回中心，描边包含两条半径边，采用 nonzero 填充。`填色 空`／`描边 空` 分别取消对应绘制。
- 转角为 0 不画像素，但仍提交并计数一条命令。`abs(转角) >= 2π` 只画一整圈，不取模归零；整圈扇形与椭圆相同，没有中心辐条，整圈弧仍只描边。

### 如观开放折线（Ru 0.19.5／如书 0.8.5）

`ruguan-polyline`／`如观折线` 插入修改顶点后重画的短示例。`图 其 折线 点阵` 只有一个必需参数，命名参数为 `点阵:`，返回空。点阵是含 2～256 个点的阵，每点恰含两个有限数坐标，绝对值不超过 100000；拒绝事实、空与句，允许重复点、退化与自交。

整条路径只描边一次，不自动首尾闭合，即使末点与首点相同仍是开放路径。忽略且不修改填色；填充区域使用 `多边形`。提交时深复制点阵及每个点，之后修改原点不移动旧折线。`描边 空` 或零长度仍计为一条命令。

### 如观三次贝塞尔（Ru 0.19.6／如书 0.8.6）

`ruguan-bezier`／`如观贝塞尔` 插入控制折线与两条曲线的短示例。签名为 `图 其 贝塞尔 起横 起纵 控一横 控一纵 控二横 控二纵 终横 终纵`，八参均必需；命名参数精确为 `起横:`、`起纵:`、`控一横:`、`控一纵:`、`控二横:`、`控二纵:`、`终横:`、`终纵:`，同次调用不混用位置和命名实参，返回空。全部坐标为绝对值不超过 100000 的有限数，拒绝事实、空与句。

曲线从起点到终点，两个控制点塑造曲线，非必过点；不是二次贝塞尔，也不是穿过四点的插值曲线。原生开放路径只描边一次，不自动闭合，忽略且不修改填色；允许重合点、退化与自交。`描边 空` 仍计为一条命令。

这三个片段均在如书 Python 或显式 browser-js 中运行，安装扩展不升级解释器。如观绘制冻结提交时的坐标、样式、变换与裁剪；保存／恢复、回调重置规则、2048 条／约 256 KiB 帧预算不变。`弧`、`扇形`、`折线`、`贝塞尔` 及它们的参数名都是普通名称，仅成员名在 `其` 后提供词法提示，不新增保留字。普通 CLI／`check` 不支持画布；纯构色片段仍可在 Python CLI `run` 中单独运行。

## 实用标准库（Ru 0.12.0+）

输入 `ru-text`、`ru-math`、`ru-random` 分别插入文本、数学和固定种子随机示例；`ru-array` 插入阵的删、弹、查示例。所有默认示例可直接运行。模块用别名导入后，按普通算调用规则传参：`数学 其 幂 2 5`、`文 其 定点 3.5 2`。竞赛模块使用 `如:竞`，可视模块使用 `如:观`，旧 `如竞`、`如观`、`如:竞赛` 导入名已移除，无兼容别名；不要同时尽取含重名函数的模块。

`阵 其 删 位:1.` 与 `阵 其 弹.` 原地修改阵并返回移出的元素，别名共享修改；弹是无参内置成员，不写 `()`，空阵弹出和越界删除报普通运行错误。`阵 其 查 值:目标.` 返回首个相等项的零起点位置，未找到为空；`典 其 查 目:目标.` 返回目对应的相。阵查按开始时的浅快照比较，相等方法若修改原阵，返回位置仍属于快照。

只在 `其` 后给普通成员名 `删` / `弹` / `查` 上下文着色和规则提示；不解析接收者类型，同名自定义成员可能有不同含义。文本、数学、随机导出的普通算名不当作保留字全局高亮。随机库为可复现的非加密伪随机；洗牌返回浅复制阵，不改原阵。完整参数、数值边界和随机算法见[实用库规范](https://github.com/uppet/ru-language/blob/wip/docs/practical-libraries.md)。

## 事实与典（Ru 0.10.0+）

`事实` 是独立类型，字面量为 `真` / `假`，不等同于数 `1` / `0`。`为 事实` 按真假规则转换：**只有 `空` 和 `假` 为假值**；`0`、空句、空阵和空典都为真值。比较、`非`、`且`、`或` 返回事实，`且` / `或` 保留短路。迁移旧代码时，检查数值条件、与 `0` / `1` 比较的判断结果以及带 `为 数` 的布尔参数。

```ru
方向 取 典:
    ‘上’ 对 0.
    ‘下’ 对 2.
成.
显 方向 其 查 目:‘上’.
方向 其 增 目:‘左’ 相:3.
显 方向 其 除 目:‘下’.
显 方向 其 量.
方向 其 逐目 作 目, 相:
    显 目.
    显 相.
为.
显 0 为 事实.
```

空典写 `典: 成`；`典` 也用于类型标注。`典` / `成` 是保留字，原来以它们命名的标识符需要改名，`完成` 等较长名称不受影响。另可使用符号典表达式 `{'心': 0, '意': 1}` 与空典 `{}`，同原有 `典: … 成` 共存；表达式位置的大括号是典，语句位置则是局部作用域块。全角 `｛｝`、中文冒号与逗号同义，允许尾逗号；带参调用作为目或相时用括号包住，以免调用吞掉外层逗号。

方法 `查 目`、`增 目 相`、`除 目`、`逐目 回调`、`量` 均是普通名称。`增` 返回自身，`除` 返回事实，`量` 返回目数。`逐目` 接受有两个位置参数（目、相）的 `算` 或 `作`，按调用时的无序快照遍历，不能依赖顺序。形目需自定义 `同(其他)` 返回事实、`印()` 返回安全整数数值，并保证相等目的印值相同。

Ru 0.12.1 起，典的命名参数统一为 `查 目:`、`增 目: 相:`、`除 目:`；旧典参数名 `键` / `值` 不再接受。位置调用不变，`逐目` 的参数名仍为 `回调`，回调内部的两个名称可自定。阵的 `查 值:` / `增 值:` 不变。`dian-api` 插入可运行的命名参数示例，需要 Ru 0.12.1+。

输入 `dian` / `典` 插入完整配对块，`dian-empty` 插入空典，`dian-each` 插入逐目回调，`fact` 插入事实参数函数。在 `典:成` 之间按 Enter，会把内容和 `成` 分开并缩进；普通多行典头与 `成` 支持缩进/退格规则。为避免类型标注被误作块头，`典` / `成` 不注册为无条件括号，也不在键入普通名称时自动插入 `成`。嵌套典、字符串、注释和较长 Unicode 名称的高亮边界有回归覆盖。

`dian-symbol` / `符号典` 插入符号典，`dian-symbol-empty` 插入 `{}`。`{}` / `｛｝` 支持配对、自动补全和成对 Enter 缩进；字符串与注释内不自动补全。高亮仅标记词法边界，不验证典的目相语法。

悬停 `事实`、`真`、`假`、`典`、`成` 可查看规则。扩展只提供编辑支持，须单独升级解释器到 **Ru 0.10.0+**。

## 省略参数类型（Ru 0.9.0+）

有名、匿名 `算` / `作` 和方法的声明参数可省略 `为 类型`，表示接受任何值，包括 `空`。同一个参数表可混用省略和显式类型，以空白或逗号分隔；显式类型继续检查，每个参数仍必须传入。没有新增类型关键字，也没有默认参数、变长参数或调用实参混用。

```ru
算 原样 值:
    得 值.
法
算 选择 值, 次数 为 数:
    得 值.
法
回调 取 算 值: 得 值. 法.
显 原样 空.
```

原有带类型片段继续可用；`suan-any` / `zuo-any`、`lambda-any` / `proc-any` 和 `suan-mixed` 提供省略或混合类型片段。悬停 `算` / `作` 可查看规则。运行须单独更新解释器至 **Ru 0.9.0+**，VSIX 不包含解释器。

## 过程提前结束（Ru 0.8.0+）

在当前 `作` 内写 `完.` 或 `完。`，提前正常结束并返回 `空`；不带表达式。自然执行到 `作` 末尾也返回 `空`，不再返回空句 `''`。`完` 是语句，块仍用 `为` 收尾；它不会让编辑器减少缩进。仅能结束当前过程，不能用于顶层或嵌套的 `算`；`算` 的 `得` 返回规则保持不变。

输入 `wan` / `完` 可插入提前结束语句，悬停 `完` / `作` 可查看规则。扩展只提供编辑支持；运行这些语义须单独更新解释器到 **Ru 0.8.0 或更高版本**，安装 VSIX 不会升级解释器。旧版按空句判断过程结果的代码需要改为按 `空` 判断。

## 注释、类型与悬浮提示

默认行注释切换生成 `批.`，块注释切换生成 `解.` / `释.`；补全模板也提供这两种形式。标记的句点可换成 `。`，但词与句点之间不能插空格。`批.` 到行末结束，`解.` 到第一个 `释.` 或 `释。` 结束，不嵌套；块内引号也不保护结束标记。`批注`、`解说`、`甲批.` 等名称不会开启注释，字符串里的标记不生效。原来的 `#` / `//` 仍支持。

`形` 声明类型名，用于标注、`如` 与 `新`，不能作为普通值赋给别名、传参或返回。模块中的形可通过 `尽` 导入，或由模块导出的工厂返回实例；不提供模块限定类型语法。

鼠标悬停于代码中的 `取`、`算`、`作` 可查看闭包赋值规则：先写当前局部已有绑定，再写已有的非模块捕获绑定，否则建立局部；不会隐式改写模块绑定。`救` 块中的直接 `取` 写救块局部，内部闭包可捕获它。`形` 也有类型名说明。提示只解释一般规则，不声称已分析某个名称的具体绑定。字符串、注释及较长名称内部不显示这些提示。

## 运行与输入

打开 `.ru` 后按快捷键。未保存 / 新建文档会先询问“保存并运行”；取消保存就取消运行，不执行磁盘上的旧版本。默认相当于：

```text
python3 -u /absolute/path/to/ru run /absolute/path/to/current.ru
```

使用 VS Code 的 `ProcessExecution` 传递独立参数，不拼接 shell 命令。同一文件仍在运行时，再按快捷键会提示先结束现有任务，不重复创建进程，也不把命令误送入正在读取的 stdin。结束后可再次运行，复用该文件的任务终端。不同文件可并行运行。

终端自动获得焦点。逐行输入后按 Enter；需要读到 EOF 的竞赛程序，在 macOS / Linux 空行按 Ctrl+D，Windows 通常按 Ctrl+Z 后 Enter（具体由终端决定）。Ctrl+C 中断程序，也可使用终端垃圾桶 / **Tasks: Terminate Task**。`读入` 会读取剩余标准输入，可能要发送 EOF 才开始输出；`蓄出` 最后须显式 `出 其 清.`。

退出后的结果留在终端。找不到 Python / rulang 的错误也在终端显示；修正解释器或 CLI 路径，再运行即可。

## 设置

| 设置 | 默认 | 用途 |
| --- | --- | --- |
| `ru.interpreterPath` | 空 | Python 可执行文件；空值采用平台默认名 |
| `ru.interpreterArguments` | `["-u"]` | Python 前置参数，逐项传递 |
| `ru.cliPath` | 空 | `ru` 脚本路径；空值使用 `-m rulang` |
| `ru.workingDirectory` | `${fileDirname}` | 程序的工作目录 |
| `ru.programArguments` | `[]` | `--` 后传入元初的参数，逐项传递 |

路径设置支持 `${fileDirname}` 和 `${workspaceFolder}`（当前文件所在的工作区文件夹）。相对路径基于该工作区文件夹；无工作区时基于当前文件目录。未打开工作区却引用 `${workspaceFolder}` 会明确报错。参数数组不展开变量，也不解释 shell 表达式。由于 VS Code 任务本身会解析 `${...}`，包含这种字面串的文件名或参数会被明确拒绝（不会替你展开或执行它）；请先重命名文件或去掉该参数。

如程序需要从项目根目录读取数据，可设置 `ru.workingDirectory` 为 `${workspaceFolder}`。远程 SSH / WSL / 容器场景中，解释器与路径都属于运行扩展的远程环境，而不是本机。

## 边界与安全

高亮是词法辅助，不等于编译检查。函数名称仅在行首声明头部着色；表达式中的匿名参数按普通名称着色，复杂单行嵌套不做语义推断。`终` 只在独立行结束词形式中着色，其他位置按普通名称处理；无完整语法树时无法证明它正处于恢复块中。自动缩进偏保守；多行头部、跨行字符串及复杂单行嵌套可能需要手动调整。`为` 同时用于类型、转换与过程结束，因此不把关键字冒充括号匹配。

运行命令只在受信任工作区可用，激活、编辑和打开文件不会执行代码。仅支持扩展宿主文件系统上的已保存文件；不支持浏览器版 VS Code 或只读虚拟文件系统的运行。执行用户源码本身可能读写文件或发起网络操作，运行前请审阅。扩展没有遥测、自动下载解释器、联网生成或后台运行。

## 独立作用域块

```ru
值 取 1.
段:
    值 取 2.
    显 值.
落.
显 值. 批. 仍为 1
{
    局部 取 3.
    显 局部.
}
表 取 {'心': 0}. 批. 表达式位置仍为典
```

`段: … 落.` 与语句位置的 `{ … }` 建立相同的局部作用域，全角标点同义。空 `{}` 在语句位置是空块，在赋值、返回或调用实参等表达式位置是空典。读取沿词法环境向外查找，块正文直接 `取` 只写本层，不改写外层同名绑定；退出后局部名不可见。`若`、`循`、`试` 不额外建域。内部闭包可捕获块局部，并继续遵循原有闭包写入规则。成员与下标写入仍修改目标对象。`得`、`完`、`破` 继续作用于所属函数、过程、循环。

输入 `duan` / `段` 或 `scope` / `作用域块` 插入片段；`段:落.` 之间 Enter 成对缩进。`段`、`落` 是上下文名称，不是全局保留字；`其 段`、`段落`、`落叶` 与普通名称绑定保持原义。高亮只保守识别行首或句点/花括号后开启的 `段:`，花括号统一标记为配对分隔符，不代替解析器判断块/典。字符串和注释中的结束符不会结束高亮块。跨行复杂头部可能只有基础词法高亮；悬停只解释规则，不做绑定解析。

需要包含独立作用域块功能的新版如言解释器；升级扩展本身不会升级解释器。

## 符号赋值

`值 := 1.` 与 `值 取 1.` 同义，支持名称、成员和下标目标；`：=` 同义，必须连续，不接受 `: =` 或全角等号。它仍是语句，不引入赋值表达式；`尽 取` 是独立导入语法，不替换成 `尽 :=`。命名参数 `名:值`、典的键值冒号和 `段:` 块头保持不变。输入 `assign` / `符号赋值` 插入片段，悬停运算符查看相同写入规则。

## 运行与编译诊断

“运行当前文件”的任务输出通过 `$ru` problem matcher 显示到 Problems，并高亮及导航到错误所在行。诊断使用 `文件:行:列: error: 中文类别：说明`，兼容旧版不带 `error:` 的输出；stdout/stderr 保持在交互任务终端。Windows 盘符、中文和含空格的真实路径不需加引号。 普通任务会缓冲当前文件的 Problems 诊断，通常在进程结束后发布；等待输入时请先在终端交互，错误原文仍实时显示在终端。重跑会更新诊断，无错误完成后会清除旧诊断。

这里只承诺行定位：如言文本中的行、列均从 1 起算，列按 Unicode 码点；VS Code 列按 UTF-16，因此 matcher 不消费列，不会把 emoji 等非 BMP 字符前后的列伪装为精确位置。原列号仍完整显示在终端。`rushu://…` 和 `<…>` 虚拟来源不映射为磁盘文件，如书自行处理其结构化诊断。

自定义 check/build 或生成程序运行任务也可设置 `"problemMatcher": ["$ru"]`。默认要求诊断使用绝对文件路径；任务输出相对路径时，使用基于 `$ru` 的 matcher 并把 `fileLocation` 覆盖为 `["relative", "实际源码基准目录"]`。此功能在手动运行/编译后工作，不自动发送源码或启动语言服务器。

C 运行时没有可靠列号时使用 `文件:行: error: 中文类别：说明`，同样识别并导航到该行；不伪造列号。

阵成员 `排序`／`另成` 提供上下文高亮、参数提示和「阵排序另成」完整示例片段。排序可省略先于（同类有限数／句／同一形身份的单参算先于），或传入返回事实的二参算；另成须传一参算，不接受作。两者返回新浅复制阵，保留共享引用，空阵也验证回调参数。旧如:竞三路排序与现有比较运算符不变。提示只按成员名称解释，不判断接收者类型。

阵 `逐位 回调:` 接受二参算或作（位、值），按初始浅快照顺序遍历；典 `逐目 回调:` 接受（目、相），保留无序浅条目快照。两者忽略回调结果、整体返回空，空容器也验证回调。旧典列会给出迁移错误，没有别名；目录列不变。回调内完只结束当前作，不能破出遍历。
